Composite nodes
→ Sequence runs children until one fails.

Memory decorators
M→ Mem.Seq resumes from last running child next tick.
M? Mem.Sel skips already-succeeded children.

Time decorators
⏱ Timeout fails if child takes too long.
❄ Cooldown skips re-execution for N ticks.

Multi-robot
